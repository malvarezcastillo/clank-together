    Paste one line

    It installs td (a single program, nothing else needed besides git), sets up the workspace and connects your AI.

    Windows (PowerShell):

    $env:TD_TOKEN='<token>'; irm https://saty.dev/install.ps1 | iex

    Linux:

    curl -fsSL https://saty.dev/install.sh | TD_TOKEN=<token> sh

    Any AI that supports MCP works (Claude Code, Claude Desktop, Cursor, Windsurf, VS Code, Cline, Codex, Gemini CLI, ...). Claude Code is connected automatically; for the others the installer prints the settings. Then ask your AI to read AGENTS.md and claim a task, or take a peer review.
